# Installing FileFlow

Welcome to FileFlow! FileFlow is a robust, privacy-first desktop application designed to supercharge your file management workflows on macOS and Windows.

## Downloading FileFlow

You can always download the latest stable release of FileFlow from our [GitHub Releases](#) page.

- **macOS Users:** Download the `.dmg` file.
- **Windows Users:** Download the `-setup.exe` installer.

## Installation Instructions

### macOS
1. Open the downloaded `.dmg` file.
2. Drag the **FileFlow** icon into the **Applications** folder.
3. Open FileFlow from your Applications folder or via Spotlight.
4. *Note:* If you see a warning that the app was downloaded from the internet, click **Open** to proceed.

### Windows
1. Double-click the downloaded `-setup.exe` file.
2. The installer will guide you through the setup process.
3. Once complete, FileFlow will launch automatically, and a shortcut will be added to your desktop.

## First Run & Privacy

FileFlow is built with a strict **Local-First Privacy** model:
- **No Internet Required:** All core features (Organizer, Renamer, Converter) run entirely on your machine.
- **Zero Telemetry by Default:** We respect your privacy. Crash reporting and analytics are strictly **disabled by default**. 
- **Opt-In Only:** If you would like to help us improve FileFlow, you can enable anonymous crash reporting in the application Settings.

## Built-In FFmpeg

FileFlow's High-Speed Converter comes bundled with a lightweight build of FFmpeg. You do not need to install FFmpeg separately to use the conversion features. It works entirely out-of-the-box!
