# 08-v2.0-Platform-Foundation.md

Cross-reference: `docs/PLATFORM-FEATURES-V2.md` v2.0 section for full feature list and rationale.

## Dashboard

- [ ] Replace direct-to-tools launch with a Dashboard landing view.
- [ ] Widgets: storage overview, top file types (chart), recent jobs, active jobs, favorite folders, today's activity, weekly stats.
- [ ] Wire dashboard stats to the SQLite/Drizzle history + file-index data (no separate stats pipeline).

## Smart Duplicate Finder

- [ ] Implement exact-duplicate detection via content hashing (worker_threads, per `docs/TECH-STACK.md`).
- [ ] Implement near-duplicate detection for images (perceptual hashing).
- [ ] Extend duplicate concept to video/audio/documents (define matching strategy per type).
- [ ] Duplicate resolution UI: preview, delete safely, move, merge — reusing the shared preview-then-commit component (`docs/DESIGN-SYSTEM.md`).
- [ ] Persist `DuplicateGroup` entity (see `docs/DATA-MODEL.md`) with resolution status.

## Large File Analyzer

- [ ] Interactive treemap component (largest folders/files).
- [ ] Charts: extension usage, old/unused/recently-added breakdowns.

## Advanced Search Engine

- [ ] Build background indexer (worker_threads) populating `SearchIndexEntry`.
- [ ] Support regex, wildcard, metadata, and basic content search.
- [ ] Support natural-language-style filter parsing (e.g., "PDFs larger than 100MB modified last month") — define a constrained query grammar rather than a full NLP model for v2.0.
- [ ] Saved searches.

## File Preview System

- [ ] Implement preview renderers for: images, video, audio, PDF, code, Markdown, JSON/CSV, fonts, 3D models, Office docs.
- [ ] Reuse existing preview-row UI patterns from MVP where applicable.

## Multi-tab Explorer

- [ ] Tab management in Zustand (new store).
- [ ] Split/dual/quad pane layout.
- [ ] Drag-and-drop between panes.

## Cross-Cutting (aligned to this phase per PLATFORM-FEATURES-V2.md)

- [ ] Recycle Center (own retention-policy trash, not OS trash) — pairs with Duplicate Finder's delete action.
- [ ] Storage Analytics charts (pairs with Dashboard).
- [ ] Keyboard Power User Mode baseline (extends MVP accessibility work).
- [ ] Notifications Center (extends MVP OS-notification integration into an in-app panel).
- [ ] File Insights (most modified/unused/duplicated) — pairs with Dashboard.
- [ ] Theme Engine v1 (glassmorphism/dark/light/OLED base — full dynamic-accent/custom-theme work can extend into v2.1–v2.2).
