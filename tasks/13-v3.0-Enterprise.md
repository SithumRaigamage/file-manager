# 13-v3.0-Enterprise.md

Cross-reference: `docs/PLATFORM-FEATURES-V2.md` v3.0 section. **Do not begin this phase before single-user product-market fit is established** (see `docs/PRODUCT-STRATEGY.md` roadmap rationale) — enterprise features target a different buyer and support model.

## Multi-User & Collaboration

- [ ] Multi-user profiles on a single install (or shared team deployment — decide model before building).
- [ ] Shared workflow templates across a team.
- [ ] Team automation rules.

## Governance

- [ ] Audit logs (who did what, when — extends the existing undo/history/command-event architecture from v2.1).
- [ ] Role-based permissions (RBAC).
- [ ] Policy management (org-wide rule/workflow constraints).

## Deployment & Operations

- [ ] Remote execution agents (run FileFlow automation on managed machines).
- [ ] Centralized settings management across an org's installs.
- [ ] Opt-in telemetry and diagnostics — must remain explicitly opt-in, consistent with FileFlow's local-first positioning established from MVP onward (`docs/PRODUCT-STRATEGY.md`).

## Security Center

- [ ] Permission manager, safe-delete policies, encrypted vault.
- [ ] Checksum verification, malware-scan integration.
